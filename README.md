# Portfolio: Toirov Diyorbek

Telegram bot dasturchi portfoliosi. Toza HTML/CSS/JS, kutubxonasiz. Sayt: https://devolopertoirov.github.io/portfolio/

- Matnlar (3 til): `content.js`. Bot holati: `status.json` (`{"BotUsername": 1}`).
- Forma: `worker.js` ni Cloudflare Worker sifatida joylab, manzilini `content.js` dagi `FORM_URL` ga yozing.
- Statistika: Umami/Plausible skriptini `index.html` ga qo'ying.
- Deploy: `main` ga push qilinsa, GitHub Pages avtomatik yangilanadi.
